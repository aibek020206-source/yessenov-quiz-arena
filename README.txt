# QUIZ ARENA — Yessenov University

## Қажет болады
- Windows 11 ноутбук
- Node.js орнатылған болуы керек
- 20 қатысушының телефондары
- Барлығы бір Wi-Fi желісіне қосылуы керек

## Іске қосу
1. ZIP файлын ашыңыз.
2. `law_quiz_game` папкасын ашыңыз.
3. Папка ішіндегі бос жерді басып, Shift + оң жақ батырма → "Open in Terminal" таңдаңыз.
4. Мына команданы орындаңыз:

   npm install

5. Сосын:

   npm start

6. Компьютерде көрсетілгендей браузерден мына бетті ашыңыз:
   http://localhost:3000/host

7. Экрандағы QR-кодты қатысушылар телефондарымен сканерлейді.
8. Телефондар мен ноутбук бір Wi-Fi желісінде болуы керек.

## Ойын тәртібі
- 20 адам қосылады.
- Жүргізуші «Командаларды бөлу» батырмасын басады.
- Бағдарлама 5 командаға 4 адамнан бөледі.
- Әр командадан бір лидер кездейсоқ таңдалады.
- Лидер ғана өз телефонынан команда атынан жауап береді.
- Сұрақ компьютерде және телефонда көрінеді.
- Әр сұраққа 30 секунд.
- Дұрыс жауапқа 10 ұпай.
- 5 раунд × 5 сұрақ.
- Соңында рейтинг автоматты шығады.

## Ескерту
Бұл нұсқа жергілікті Wi-Fi желісінде жұмыс істейді. Қатысушылардың телефондары мен жүргізушінің компьютері бір Wi-Fi желісіне қосылуы қажет. Интернет арқылы әртүрлі жерден қосылу үшін бөлек хостинг/сервер орнату керек.
